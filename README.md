# Ananya Enterprise
`npm i && npm run dev` | Deploy on Vercel (Vite, output `dist`; `vercel.json` handles routing).
Pages: Home, About, Services, per-service pages, FAQs, Contact, Privacy, Terms, Disclaimer, 404.
Before launch: fill every VERIFY in `src/config/business.js`, replace `public/logo.svg`, add real reviews to `reviews`, have `src/config/legal.js` reviewed by a professional, and update the domain in `sitemap.xml`, `robots.txt` and `siteUrl`. Analytics is intentionally not included.
